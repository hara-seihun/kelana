# Fit the rounded two-head score, not its floating surrogate

The [phase-cell fit](../phase-cell-fit/README.md) optimizes centered score error with real, unrounded queries. That phase need not help the direct signed-nibble score map: query rounding moves when the phase moves. For **fixed coordinate steps** there is a simpler exact search for the rounded map's *causal softmax KL*. Key and query codes are both constant between their transition angles, so the entire causal attention distribution, including any fixed contributions from other planes, is constant there. Check one phase per cell and every transition itself. This replaces a continuous nonconvex optimization with a finite choice and requires no score-error surrogate or quartic solver.

For one shared GQA plane let `k_j` be appended keys and `q_ht` the two heads' query vectors at causal position `t`. At phase `p`, encode each with `clip(floor(U(p)x/s + 1/2), -7, 7)` using fixed positive key and query steps `s_k,s_q`. For each head and position, the direct score of key `j` is `b_htj + s_k s_q <code(q_ht),code(k_j)>`, where `b` is the unchanged contribution of every other plane. The teacher is `b_htj + <q_ht,k_j>`. Apply softmax over `j<=t` and sum teacher-to-candidate KL. The codes are shared by both heads and no floating key or int4 intermediate occurs at inference.

A rotated coordinate is a sinusoid of `p`. It crosses each of the fourteen half-integer boundaries at most twice per revolution. Two coordinates therefore create at most 56 events per vector in a full revolution. With `N` keys and `H` participating query vectors, there are at most `56(N+H)+1` constant-code cells. A simultaneous key/query transition cannot hide a better isolated code combination: evaluating every exact boundary handles the tie rule. Symmetric `-7..7` labels make the **interior** map quarter-turn periodic when both planes' steps are scalar and the same phase rotates keys and queries. Half-integer ties can break that symmetry at isolated boundaries, so this executable searches the full revolution. For a single plane in the pinned two-head `N`-position causal observation, `H=2N`, giving at most `168N+1` cells before duplicate crossings. Other planes enter `b` without changing the bound. If one query vector appears in multiple rows, count distinct vectors once. This is an exact real-arithmetic finite-family optimizer, not a bit-identical FP32 result. Computing angles and loss in floating arithmetic is a numerical witness, not a certified root isolation.

`fit.py` constructs twelve keys, 24 query vectors, two causal heads and fixed scores from other planes using seed 7421. Its [receipt](receipt.json) stores every input, code image, source hash and result. The 88 key and 784 query crossings yield 873 cells over the full revolution. With steps `.75/.34`, zero-phase mean causal KL is `.03805138245`; the selected transition at phase `1.14653318237` reaches `.01739837417`, a 54.28% reduction. A phase immediately inside the cell to its right gives the same rounded code and loss. A uniform 4,096-angle full-revolution grid misses the narrow winning cell and scores `.01810235983`. This is a checked example, **not** Qwen held quality or a reason to select a new model image.

Offline, sorting events costs `O((N+H) log(N+H))` for fixed symmetric nibble ranges. The reference executable recomputes complete causal softmax at each cell. Incremental code changes can update the affected key column or query row, but the resulting normalized losses must still be charged in a real fitter. At inference this has the same signed-nibble key-cache width and score-dot count as the zero-phase fixed-step map, plus the [phase-gauge cost](../rope-commutant/README.md): two FP16 phase numbers per plane and on-demand phase/position composition. This fit adds **no online search**. It does not erase the paid binary Q/K projection, full K-norm denominator, query preparation, cache append or softmax. The deployed signed-byte query arm uses a *dynamic maximum-based step*; its other coordinate labels may change as that maximum changes. The finite cell list here does not cover that map.
