# Frozen narrow layer-0 values inside the binary prefix

The existing shared GQA value image repairs part of the first layer's damage even when layers 1–13 use the refined binary body. It does not repair the model. At unchanged or slightly lower layer-0 V/O bytes, the rank-28 image lowers gold loss by 0.758 nats on twelve later test windows and 1.278 on eight later validation windows. The smaller 192-coordinate selected image wins all twelve test windows against independent binary V/O, but loses 0.663 nats to rank 28 on the eight validation windows. Selecting its rank allocation from the test mean would be a mistake.

We froze three already trained layer-0 images. The rank-28 image is the shared V/O causal fit; the selected and uniform 192-coordinate images are the equal-rate, original-producer left-code refits. No codes or scales were trained on this panel. Each arm runs the pinned Qwen3-0.6B in BF16 with the same refined binary matrices and norms in layers 0–13, original layers 14–27 and original tied embedding/head. The independent binary V/O image is the within-prefix control. The original-V/O arm leaves the other five layer-0 body matrices binary; the original-layer-0 arm restores all of that layer. Every row has 255 teacher-forced WikiText gold targets. Test indices 52–63 follow the preceding prefix study's 32–51; validation indices 24–31 are a different corpus split. The fixture has been used elsewhere, so this is a diagnostic, not a claim of blind benchmark selection.

The selected and uniform 192-coordinate images have the same 183,552-byte V/O rate and 589,824 factor terms per token, yet their validation NLL differs by 0.473. The selected image wins over uniform by just 0.013 on test. This is another direct failure of the frozen original-producer post-O ranking as a model-loss criterion. The 28-coordinate image has 688,128 factor terms per token and 25,088 more stored bytes than either 192-coordinate image; its model-loss advantage on validation is real, but it is not a rate- or cost-matched win. The 192-coordinate selected image saves 27,416 bytes, or 0.000368 whole-model BPW, against independent binary V/O. Original V/O instead adds 6,080,488 bytes, or 0.08161 whole-model BPW. These rate differences apply to a hypothetical complete image with all other parameters held fixed; the quality panel deliberately retains original tied endpoints and layers 14–27.

The decisive remaining loss is elsewhere in the first layer. Restoring only V/O reduces test NLL by 1.332 against binary, whereas restoring all of layer 0 reduces it by 5.913 on these same twelve windows. With narrow rank 28 the test NLL is still 12.103; with selected 192 coordinates it is 11.951. The next construction should fit attention plus MLP jointly under the quantized producer, using a gold or teacher continuation objective and a paid layer-0 budget. Do not choose a native rank/cache layout from the 192-coordinate test mean. Propagate any surviving construction through the tied image and the remaining quantized layers before pricing a consumer.
