# Gold-selected gain in the paid first-layer down scales

The previous layer-0 down-sign fits lowered squared endpoint error but failed to improve held language loss. The factor image already has 1,024 FP16 down-row output scales. I kept every sign and the other MLP factors fixed, multiplied those scales by one shared candidate gain, rounded them back to FP16, and selected the gain on complete-model gold next-token loss. The scalar is a training parameter, not an extra stored parameter: the published image contains only the changed FP16 scales in the same 614,436-byte three-projection payload. The online factor terms and scale multiplies are unchanged.

The continuation uses binary body and norms in layers 0–13, shared rank-28 V/O at layer 0, original tied endpoints and original layers 14–27. The forward expands the packed factors to BF16 for quality evaluation. There is no compressed-inference timing or whole-model deployment. Six 256-token train windows select among gains 1, 1.25, 1.5, 1.75, 2, 2.25 and 2.5. The train-optimal grid point is **2**, with mean NLL **8.59578** against **10.63667** for the damaged-producer response-fitted scale image. The train loss rises again to 8.81857 at 2.25 and 8.98227 at 2.5. This is a non-monotonic complete model objective, not an endpoint-error sweep.

The two contiguous test panels score 11.20552 → 9.14852 on windows 44–55 and 11.56619 → 10.35196 on windows 56–61. Test window 58 reverses sharply, 9.83363 → 11.75968; validation window 26 also reverses, 11.07289 → 11.26084. These damaged-prefix losses are still far above the original model. The older six-window test split had already been used repeatedly for other image comparisons, so the 18-window result is evidence for this fixed train-selected image, not a blind benchmark or a good complete sub-bit model.

The mechanism is simple and surprisingly large. Minimizing first-layer endpoint distance had set the down scales to a response norm that the damaged downstream model did not want. A single shared gain across those already-paid scale slots improves held gold loss by 1.776 nats on the 18 test windows, while moving no code bit and adding no native work. This is not a proof that multiplying all MLP scales by two generalizes to other layers or producers. It suggests fitting the *composed language observation* before spending rate on signs, ranks or residuals. The next experiment should fit several coupled V/O and MLP paid coordinates on independent train text, then select on separate validation and assess a larger untouched test set. The present quality is too damaged for a native consumer choice.
