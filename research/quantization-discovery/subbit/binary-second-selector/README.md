# Fit both integer ladder boundaries to the paid binary consumer

The A7 integer ladder had allowed limited clipping before the first binary factor but forced a no-clipping choice before the second. That restriction is arbitrary once the observation is the final projection. On frozen Qwen3-0.6B `mlp_up` images, fitting one static threshold at each boundary against the complete two-factor response lowers held relative RMS from .017775 to .017412 at layer 0 and .016480 to .016311 at layer 14. The preceding first-boundary fit alone reached .017573/.016473. This is a modest but repeatable same-image response improvement, not model quality or a native speedup.

## The construction and finite search

Keep both paid one-bit sign matrices, their pre/post scales, the A7 codes, 32-coordinate groups, cap eight and the common integer scale of the [parent ladder](../binary-shifted-scales/README.md). At either boundary, the larger group step is `s=M/(63·2^e)`, and the smaller step is `3s/4`. The old selector chose the smaller step only when `m_g/(63s) <= .75` and `e<8`. We permit `m_g/(63s) <= t`, with a separately fitted scalar `t` for each boundary and projection. Codes still round to even and clip to `[-64,63]`. Each signed group dot is multiplied by its old integer multiplier `2^(9-e)` or `3·2^(7-e)`; the first common scale cancels in the second quantizer and floats enter only at the final response boundary. This preserves the integer dot and storage contracts, but intentionally changes the approximate response when clipping occurs. The old signed-int32 magnitude bound still applies because no code magnitude or multiplier grows.

For the first selector we search thirteen thresholds `.70:.01:.82`; for the second, seventeen `.70:.01:.86`. The script enumerates all 221 pairs and takes the minimum complete-output train RMS, not a linear pre-second-quantizer surrogate. That is an exhaustive optimum **on this grid and these 32 training activations**, not across every continuous threshold or all quantizers. It also reports one-boundary selection and the sequentially fitted pair. Each extra dynamic threshold comparison replaces a `.75` constant comparison already charged by the group quantizer. The sign-word bitplane dots, group-scale reduction and final floating multiplies have the same counts as the safe ladder. There are two offline scalar thresholds per projection instead of one; group clipping does not introduce an exception stream. Actual instruction schedule, quantizer preparation and GPU occupancy remain unmeasured.

Layer 14 is instructive: the best pair changes the first threshold from the previous first-only `.76` to `.78`, even though both use `.77` for the second factor. Holding the first threshold at `.75` and fitting only the second reaches .016417 held; neither isolated threshold explains the pair's .016311. At layer 0, the sequential `.77/.78` fit reaches .017410 held, slightly better than the train-optimal grid pair's .017412. We report the train-selected pair; choosing by held data would leak the observation. The new second selector clips only 22/13 of 12,288 second-stage activation codes across 32 held inputs, yet its perturbations reach every output through the second sign factor. The same paid-image FP64 response is the denominator for every arm.
