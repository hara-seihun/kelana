# Calibrated four-bit converter

`calibrated.py` converts the pinned Qwen3-0.6B checkpoint into 197 actual packed matrices. It stores each group of 128 input columns as unsigned four-bit nibbles with an FP16 scale and FP16 origin per output row. A decoded coefficient is `code * scale + origin`. It stores the tied input embedding and vocabulary head once, leaves the 65,536 norm coefficients BF16, and charges the eight-byte shape descriptor in every matrix. The complete payload is 316,749,352 bytes, or 4.251313 bits per unique model parameter. The `.npz` container size is separate.

The tied matrix uses rowwise affine rounding. The body starts with the same rowwise group grid, searching three clipping ranges with alternating affine least squares and integer assignments. For each projection it then uses a damped inverse-Cholesky factor of the full input covariance. Sequential rounding compensates error inside a 128-column group and propagates the accumulated group error to every later input column. A single factor is shared across projections with the same input producer. Within each decoder layer, the procedure fits Q/K/V first, O against their quantized producer, gate/up against the quantized attention branch, and down against the quantized MLP producer. The next layer's BF16 activation cache is generated by that complete quantized layer. Calibration uses expanded training windows 0 through 31, 256 tokens each. Validation and test windows do not enter fitting.

`asymmetric_rtn.py` fits the same stored format, scales, origins and coefficient grid without activations or error compensation. Its independent CPU fit of the tied embedding can differ at floating rounding boundaries from the GPU fit, so body-only evaluation holds the identical BF16 tied matrix fixed. The parent also evaluated an exact-shared-head manifest: affine RTN body plus the identical calibrated tied image. It gets 3.980601 test and 4.046508 validation NLL, versus calibrated 3.795795 and 3.851346. This isolates the body-method difference even in the complete quantized model.

`share_tied.py --body BODY_MANIFEST --tied TIED_MANIFEST --out NEW_MANIFEST` reproduces the shared-head control without copying or modifying weights. `save_norms(root)` materializes all charged BF16 norms as uint16 bit arrays in `norms.npz` with a hashed `norms.json` receipt. Norm images are identical in both banks. The initial evaluated manifests are retained unchanged; their supplemental norm receipts hold the same already charged coefficients.

The packed images and manifests live in `/path/to/workspace/data/kelana-subbit/q4-diagnostic/{calibrated,asymmetric-rtn}/`. Each manifest has 197 `{key,path,sha256,payload_bytes}` entries and a complete paid total. `calibrated.decode(path, device='cpu')` expands the actual nibbles, scales and origins to an FP32 tensor for the matched BF16 execution in `evaluate.py`. The source does not claim a packed inference kernel or runtime speed.

To reproduce, use the project's fish-s2-pro Python environment and Bonsai's GPU reservation for `calibrated.py`:

```bash
P=/path/to/workspace/data/fish-s2-pro/venv/bin/python
C=/path/to/workspace/projects/kelana/research/quantization-discovery/q4-diagnostic
B=/path/to/workspace/projects/bonsai-halo/tools/run-batch-compare
$B --runtime-max 48s --exec "$P" "$C/calibrated.py" --embedding
for layer in $(seq 0 27); do
  $B --runtime-max 48s --exec "$P" "$C/calibrated.py" --layer "$layer"
done
"$P" "$C/asymmetric_rtn.py" --embedding
for layer in $(seq 0 27); do "$P" "$C/asymmetric_rtn.py" --layer "$layer"; done
```

The scripts refuse to replace existing images. Use a fresh `--out` directory to repeat a fit, then pass the new manifest and decoder to `evaluate.py`. The calibrated script can also fit one layer group with `--group 0..3` if a full layer exceeds the bounded GPU reservation. Resuming a partially fitted layer loads its existing images before it captures later producers. Keep the same calibration window count and damping across invocations.

The matched test and validation receipts are under `/path/to/workspace/data/kelana-subbit/q4-diagnostic/`. On 32 held test windows, BF16 reference NLL is 3.639218; odd-level symmetric group128 RTN complete is 4.451341; affine RTN complete is 3.981112; calibrated complete is 3.795795. The body-only sequence is 3.639218, 4.406165, 3.951311 and 3.767451. On eight held validation windows, affine RTN complete is 4.045799 and calibrated complete is 3.851346, against BF16 3.668815. The body-only affine/control pair is 4.021238 versus 3.810551. At the same paid rate, response fitting improves test complete NLL by 0.185316 and validation complete NLL by 0.194453 over the matched affine RTN format. These are decoded-weight quality measurements, not packed execution measurements.
