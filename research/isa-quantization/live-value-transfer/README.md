# Live-value transfer: score capacity is not output capacity

The observation is the **projected current-query value/output response** on actual two-position histories `[y,x]`, not the attention law itself. A binary head with probability `p_xy` for the prior position, projected current value `a_x`, and projected prior value `b_y` emits

```
O_xy = a_x + p_xy (b_y-a_x).                                      (1)
```

Current labels `x` and prior labels `y` are separate finite source alphabets; every declared pair is a reachable `[y,x]` history. The projection can include a fixed linear output map. Other heads, residual streams, later recurrent state and contexts are outside this particular observer unless included explicitly. All static values, probabilities and any context-dependent carrier must be paid if used by a program. The independent [causal-odds-rank](../causal-odds-rank/README.md) floor certifies **attention KL** for a separable prior-key score family; it is not automatically an output-error floor.

## Two useful general results

**Exact joint-value transfer at every positive-gap cell.** Let `s_x,t_y` be positive, `0<s_x<1`, `0<t_y<=1`. Give the teacher current value zero, every prior value one, and probabilities `p_xy=s_x t_y`. Give the candidate query-only probability `q_xy=s_x`, current value zero, and prior value `t_y`. Then `O_xy=s_x t_y` for every pair, with **strictly positive teacher and candidate value gaps at every cell**. The candidate's prior-key odds matrix is zero after row centering: `Lhat_xy=logit(s_x)` is entirely a current-only offset `b(x)`. It needs a value carrier for `t_y`; that carrier is not free or magically a zero-bit key. The teacher's score odds `logit(s_x t_y)` need not have low centered rank.

In fact the separation is **arbitrarily large in rank**. For any `m`, choose `m+1` distinct positive `t_j<=1` and `m` suitable distinct `s_i∈(0,1)`. With `t_0` a reference key, the functions

```
F_j(s) = logit(s*t_j) - logit(s*t_0),       j=1,...,m
```

are linearly independent. Their derivatives are `t_j/(1-s*t_j)-t_0/(1-s*t_0)`. A linear relation among the derivatives is a rational-function identity; multiply by the common denominators and evaluate its polynomial at the distinct poles `s=1/t_j`. Every coefficient vanishes. Linear independence of the functions implies some `m` evaluation points yield an invertible `m×m` matrix; continuity lets them be chosen rational. Thus the teacher row-centered log-odds matrix has rank `m`, while the value-transferred candidate has centered score rank zero and exactly the same **nonzero** live output on all `m(m+1)` pairs. Fixed values would identify every probability (see below); the freedom to **jointly** change the paid value map makes the difference. No statement about all later contexts or a full-model gain follows.

**A consumer-specific error floor which survives arbitrary joint value fitting.** Conversely, for any `H` binary heads with prior-probabilities `q_h(x)` independent of `y` (current-only logit offsets), arbitrary jointly chosen projected current values `a_h(x)` and **shared prior-only** projected values `b_h(y)`, the full output is `Σ_h [a_h(x)+q_h(x)(b_h(y)-a_h(x))]`. Center over the prior labels. Each head contributes the outer product `q_h(x)*(b_h(y)-mean_y b_h(y))`; hence the query×prior centered output matrix has rank at most `H`. For target output matrix `O`, every such candidate satisfies

```
mean_xy ||O_xy - Ohat_xy||² >= (1/(mn)) sum_{j>H} sigma_j(O C)²,  (2)
C=I-11ᵀ/n,
```

with output channels flattened into the prior-column axis and the corresponding block centering. This follows by Frobenius contraction under centering and Eckart–Young, **even when Q, K, V and the linear O projection are jointly refit** within the stated feature-dependence contract. Unlike attention-KL, (2) directly measures the live consumer. It need not be positive for the constructive family above: its output is rank one. It also need not apply to a prior-dependent query, a prior key changed by current x, context-dependent values, a nonseparable readout, or nonlinear downstream mixing before the measured boundary. A rank-one *score* program with sigmoid can have high-rank output; (2) is specifically for query-only probabilities / centered score rank zero, not all score ranks.

For fixed candidate values, (1) gives a complementary exact condition: if `b_y≠a_x`, preserving output forces preserving `p_xy`; if `b_y=a_x`, that probability is unobservable at this boundary. For **jointly chosen vector values**, a complete exact feasibility reduction is available: for each paid candidate value choice `(a_x,b_y)`, require `O_xy-a_x` to lie in the open line segment from `0` to `b_y-a_x`; on nondegenerate segments its unique coefficient is `q_xy=⟨O_xy-a_x,b_y-a_x⟩/||b_y-a_x||²`. Degenerate segments require `O_xy=a_x` and impose no probability constraint. A separable `r`-feature score program exists for those values iff the prescribed active-cell log-odds admit a real completion whose row-centered rank is at most `r` (factorization plus current-only offsets). This is a **decision reduction conditional on values and paid feasibility**, not a claim that the joint value optimization is free or easy. For approximate output, `dist(O_xy,[a_x,b_y])²` is an immediate per-cell lower bound independent of score fitting; a finite paid value menu can use these segment floors before rank completion.

## Exact paid three-query/four-prior witness

Take `s=(1/10,2/5,4/5)` and `t=(1/8,1/2,3/4,1)`. The teacher's twelve rational probabilities are the outer product `s*t`, its prior values are all one, and its current values zero. Candidate probabilities are `s_x` on **all four prior labels**; its prior values are `t_y`. Both output matrices are exactly `s*t` and all values/gaps are positive. All teacher probabilities are in `(0,1)` and the candidate uses a query-only bias `b(x)=logit(s_x)`. It can be realized by a one-coordinate physical binary-attention scorer with constant zero prior score and a current-token self score `-logit(s_x)`; this physical self carrier and the logit conversion/work must be paid rather than counted as a free rank-zero head. The teacher can be realized with three query-basis coordinates and prior score columns `logit(s_x*t_y)`, with zero self scores; no unreachable off-diagonal self-pairs are assumed.

Subtracting the fourth log-odds column from the first three gives a `3×3` minor in `[-.018359498,-.018214321]` by exact rational-log interval arithmetic, so the teacher's **centered odds rank is three**, not a numerical tolerance. The candidate's mean binary attention KL lies in `[.180340640,.180340641]`, while its post-value/output squared error is **exactly zero**. The positive gaps make this more discriminating than silencing a high-rank score matrix with a zero-value mask. The arbitrary-rank theorem, not this particular constant, is the result.

[`certificate.py`](certificate.py) emits and independently parses two literal rational images: [`direct.bin`](direct.bin) has all twelve teacher probabilities as one-byte numerator/denominator pairs (**24 payload bytes**); [`value-transfer.bin`](value-transfer.bin) has the three query probabilities and four prior values as seven pairs (**14 payload bytes**). The reader shape, indexing, pair decoding, fixed current value and dispatch are common fixed program code, excluded from both payload counts; no per-model table or exceptional value is hidden. The direct score/probability reader performs one indexed lookup and uses teacher value one. The value-transfer reader performs two lookups and a multiplication; to produce conventional logits from its rational odds rather than reading probability directly requires an online logit conversion (or a paid logit table). **Native work is not claimed equal.** A **strong direct-output factorization** uses the *same fourteen bytes* and computes `s_x*t_y` without constructing any attention law. Thus the result establishes a score-to-value capacity transfer and an exact cheaper-than-full-table example, **not** superiority to the strongest output-only program at comparable size. The direct 24-byte control also has exact output and zero attention KL, while the 14-byte quotient has exact output but positive attention KL. The different objective matters.
