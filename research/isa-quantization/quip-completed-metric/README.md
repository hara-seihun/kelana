# One source-conditional covariance completion, two paid quantizers

This is the predeclared changed-metric experiment following the [full-row reversal](../quip-full-row-slab/README.md), its [covariance diagnosis](../quip-covariance-transfer/README.md), the [complete source-ID moment](../quip-token-producer/README.md) and the parent's [conditional-completion theorem/witness](../covariance-completion/README.md). It fits **one** new QuIP# E8P12RVQ3B rank-zero image and **one** response-sensitive mixed group128 Q2/Q3 scalar image using exactly the same completed metric. It does not search metrics or select images on held inputs. The original train-fitted images and the new images are all scored on empirical train, uniform source-ID, completion, and previously inspected held responses.

## Frozen metric and payload

From the original 2,048×1,024 train input panel take `H=XᵀX/2048`; its range `R` has exact dimension 896. Duplicate-token count gives the upper bound, and the source study's invertible 897-row minor after adding one held row forces the original 896 distinct rows to be independent. The numerical eigenspace implementation uses the separately recorded spectral gap. The [source-owned uniform-ID moment](/path/to/workspace/data/kelana-subbit/isa-source-law/qwen3-0.6b-layer00-q-input/README.md) `G` counts each of the 151,936 pinned embedding IDs once, not by language frequency. [`metric.py`](metric.py) calculates the parent's unique matrix-divergence-nearest source completion `M=G+GP(PGP)^+(H−PGP)(PGP)^+PG`, preserving the supported block `M_RR=H_R`. It asserts rank 896 at an explicit spectral gap, supported-block discrepancy <`1e−10` (actual `2.57e−12`) and Cholesky positivity. There is **no fitted ridge/mixture parameter** in M. Its 8,388,736-byte FP64 `.npy` is an offline sufficient statistic in [the data owner](/path/to/workspace/data/kelana-subbit/isa-source-law/qwen3-0.6b-layer00-q-input/README.md), SHA256 `0775bf85e7fca7b475766d5f4cbe89ed67a1a0184ef2c04afe0bc34dffddc1c9`; it is not in the inference images.

QuIP#'s CPU E8P12RVQ3B fitter is the [existing named-method local port](../quip-full-row-slab/fit_rvq3.py) with its Hessian input changed from H to M. Its normal 1%-of-mean-diagonal algorithmic Hessian damping, Hadamard signs, E8P/E81B grids, ten block-LDLQ refinement passes, global FP16 scale and rank zero stay fixed. The residual indices are subsequently recoded by the exact 256-vector bijection to the parent's [table-free E8 root byte reader](../e8-root-program/README.md); this removes the generic 4,096-byte residual table without changing the ideal decoded map, index width or introducing model-specific metadata. The new actual 50,322-byte [`completed-rvq3-root-50322.bin`](completed-rvq3-root-50322.bin) contains 32,768 B E8P indices, 16,384 B one-byte residual root labels, 128+16 B sign vectors, 2 B global FP16 scale and the once-charged 1,024 B fixed E8P absolute table. This is a **source-completion adaptation to QuIP#**, not a reproduction of its published full-model numbers.

The new scalar fit uses the canonical [full-covariance compensated and response-refitted row fitter](../matched-rate-frontier/fit.py). For each group128, [`fit_scalar_group.py`](fit_scalar_group.py) supplies a synthetic Cholesky factor whose Gram is exactly `128 M_group` (global scaling does not alter optimum); each Q2 and Q3 code grid is fitted with existing three clipping starts/four alternations, 1% damping, and FP16 scale/origin response refit. [`assemble_scalar.py`](assemble_scalar.py) computes all 1,024 candidate downgrade gains under the **whole M**, greedily selects the same predeclared 191 Q2/833 Q3 paid group count including same-row interactions, then independently solves and FP16-rounds all 16 row fields under whole M, accepting all 128 strict M improvements. The new 50,320-byte [`completed-group-q2q3-50320.bin`](completed-group-q2q3-50320.bin) has 39,984 B Q3 codes, 6,112 B Q2 codes, 4,096 B FP16 fields and 128 B modes. Group code assignment is not a global Q2/Q3 optimum. The original control is the separately stored train-fitted image in [its owner](../quip-root-matched-scalar/README.md), not overwritten.

## Independent frozen-image replay

Relative squared error is `tr(C ΔᵀΔ)/tr(C WᵀW)`, where `C` is each declared input second moment, `W=weight[:128,:]`, and `Δ=Ŵ−W` parsed from the stored bytes. [`replay.py`](replay.py) independently decodes root E8P/E81B and every scalar 2-/3-bit group directly, without importing fit/packing functions; it checks fixture, source G, M, old and new image hashes. For the original QuIP root image the parent has separately proved exact output equality with its larger original table image. `results.json` contains the full absolute numerators and relative errors.

The M-trained QuIP image gives a **3.76% lower held relative squared error** than its own H-trained image at identical bytes, while the M-trained scalar worsens held by **0.36%** at identical bytes. Both methods improve uniform-source-ID and M responses, accepting a train loss. Thus the chosen source completion repairs part of QuIP's measured transfer failure without assuming a Gaussian producer, and does **not** uniformly improve held quality for every decoder family. The new QuIP held value is also below both scalar held values at this precise 50,320/50,322-byte endpoint. These facts do not imply global Pareto optimality or full-model language quality. The later [four-arm complete-head replay](../quip-complete-head-observer/README.md) measures the actual attention boundary: M improves root held KL .02416825→.02312622, but the original H-fitted scalar remains better at .01821224 and also wins post-O error. The source completion improves this root program without repairing its complete-consumer deficit. All held scores were computed once after images and M were fixed; they did not select a metric/fit or exported winner. A frequency-weighted language law may prefer a different image from the uniform-ID law.

The metric requires eigenspace and 1024×1024 solves/SVD-like operations during **offline preparation**, and a full vocabulary covariance from the pinned 151,936-token source. That work, ~8 MiB stored M and G each, and transient arrays are not an online compressed-reader win. Standalone inference-image data remain exactly 50,322/50,320 bytes; the root image includes 1,024 bytes of shared generic absolute table, so its model-specific portion is 49,298 bytes. Compiled reader code remains a separate once-per-pool cost, as measured for the earlier frozen images in the [native study](../quip-full-native-root/README.md). QuIP's online two Hadamards, root-byte residual dots and E8P extraction still differ from scalar code extraction/group-affine work; no native full-row latency or register/caching result is claimed. Ideal FP64 replay also does not certify emitted GPU rounding or attention continuation.

```sh
cd /path/to/workspace/projects/kelana
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
PY=/path/to/workspace/data/fish-s2-pro/venv/bin/python
$PY research/isa-quantization/quip-completed-metric/metric.py
$PY research/isa-quantization/quip-completed-metric/fit_rvq3.py
for g in 0 1 2 3 4 5 6 7; do $PY research/isa-quantization/quip-completed-metric/fit_scalar_group.py "$g"; done
$PY research/isa-quantization/quip-completed-metric/assemble_scalar.py select
for s in 0 32 64 96; do $PY research/isa-quantization/quip-completed-metric/assemble_scalar.py refit "$s" "$((s+32))"; done
$PY research/isa-quantization/quip-completed-metric/assemble_scalar.py finish
$PY research/isa-quantization/quip-completed-metric/replay.py
```

Each individual computation stays under one minute on single-threaded BLAS. Intermediate group/selection/refit records are offline reproducibility state; the two exact inference images above contain their complete paid fields. No GPU/new capture, held-chosen damping or extra compute provisioning occurred.
