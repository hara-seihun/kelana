## Immutable change and actual byte ledger

The original TurboQuant source experiment committed a **196,624 B** shared FP32 program: independent fixed128² K and V Haar-QR matrices, the fixed128² Gaussian QJL projection, and 16 B of exact-sphere four-centroid codebook (`program.fp32` SHA256 `6aa9d5a62e4763b434f8e59ee1d79322dfda8e7146846748d77bc619f171a1cf`). **Same seed 20260924, same bytes, same FP32 normalization/radii/QR/codebook and numerical sign decisions, same K3=MSE2+QJL1 and V2=MSE2.** Per token/KV head the K image remains 32 B packed 2-bit MSE indices, 16 B QJL residual signs, 4 B FP32 original norm and 4 B FP32 residual norm (56 B); V remains 32 B packed 2-bit MSE indices +4 B FP32 original norm (36 B). The new full-layer cache at 256 tokens is **256×8×(56+36)=188,416 B**, hence **385,040 B** including that single shared prepared program, equal to original TurboQuant's counted rate. The [paid gamma image](../qwen-coupled-gamma/replacement-qk-gamma.bf16) is **512 B replacement** of the original **512 B** Q/K gamma within the common **12,583,424 B** Q/K/V/O/gamma static model image: **zero incremental source bytes**. No per-model exponent list, online diagonal multiply, center, random seed asset, extra table, V recode, protected buffer or dropout mask was added. This cost excludes generic quantizer/attention instruction code shared between arms; transient decoded arrays, current scores and CPU teacher tensors are not passed off as the compact cache.

The source change was fully fixed and proven on [all 12 original windows](../qwen-coupled-gamma/results.json) **before** this candidate was encoded: 64 RoPE-pair powers `2^e`, exactly BF16-representable replacement gamma SHA256 `dd1b5b537c145a4113bdc41639de86d3875e3434125a34483d89ead581089d40`, two identical pair gains at coordinates `a,a+64`, reciprocal Q/K. It changes source Q and post-RoPE K by reciprocal powers but preserves original causal Q·K scores, probabilities and complete O bitwise in the canonical CPU reader. It was selected once from train-only coupled norm-product `C_ab` and **never** from TurboQuant image quality, held output, codebook/bit-rate choice or rank. The [exact integer-optimality certificate](../integer-gauge-balance/README.md) (for stored FP64 C interpreted as dyadics) belongs to parent theory and concerns **that norm-product objective only**, not this finite port's O error or the original unknown language distribution.

[`source.py`](source.py) independently decodes the same 512 B gamma replacement and recomputes **actual 16 original Q /8 original K BF16-projected heads**, Qwen Q/K RMSNorm+gamma and position RoPE before folding. It checks `Qnew=2^e Qold`, `Knew=2^(−e)Kold` bitwise before K rounds to the **same post-RoPE BF16 cache insertion** used in original TurboQuant and KIVI; V, O and the original FP32-post-RoPE teacher remain unchanged. There is no pre-RoPE cached key or per-key inverse rotation. Original physical V source bytes and all original V **paid cache bytes** are unchanged, not just value outputs approximately equal.

[`build.py`](build.py) calls the **unchanged donor's pure K encoder** on that new source using the identical literal FP32 program, copies each original donor **36 B V slice verbatim** for every token and all eight KV heads, emits a new actual 188,416 B packed K/V image per window, and records all 256 prefix-image and appended-row hashes. It does not rebuild the successful donor V codes. [`replay.py`](replay.py) imports the donor's **independent decoder, not its builder**, checks paid gamma/program/donor image hashes and byte-for-byte identity of all V slices, recomputes *every K and V* index/sign/radius decision against the corresponding source and paid program, checks every prefix image and selected snapshots, transforms each **changed** query with the fixed Gaussian QJL map, applies original asymmetric residual score, causal log-softmax, decoded V and complete 1024×2048 O. It checks the independently paid gamma source receipt for bitwise identity of the uncompressed original observer. [`aggregate.py`](aggregate.py) requires the original donor's matched original TurboQuant and KIVI receipts, unchanged teacher-square denominators, zero-output relative squared error **1** for every nonzero teacher output, all 12 windows and all byte/hash assertions, then aggregates summed SSE before dividing.
