# Fixed value-feedback selectivity diagnostic

This is a read-only explanation of the **same original eight held positions** (validation windows 0–3, t=128/256) in each layer. It does not tune an encoder or run a source projection, teacher/model forward, GPU experiment, or full-window query replay. Layer 0 reads the frozen original-Q/teacher/O snapshots and arrival events; layer 1 reads the frozen contextual CPU Q/K/V/teacher and its separately pinned original layer-1 O. This is teacher-forced layer-1 input, not an autoregressive feedback rollout. The independent value-feedback encoder reconstructs the saved FP32 residual from emitted codes and source BF16 values, checking the per-event phase SHA-256 receipts. The paid decoder reads the original and feedback snapshot images; both share byte-identical K2 at each position and identical recent V. All O-side arithmetic in this diagnostic is FP64 over decoded FP32 fields, saved FP32 queries/sources and original BF16 O. The independently maintained paid FP32 CPU observers agree to <1e-6 SSE per state; FP64 output hashes here are diagnostic hashes, not their FP32 output hashes.

For each query head, set `p=softmax(Q K2ᵀ / √128)` and `e_j=V̂_j−Vsource_j`. We record `b=O concat_heads(p Vsource)−teacher`, `E=O concat_heads(p e)`, and the actual full error `b+E`; exact output SSE is `||b||²+||E||²+2⟨b,E⟩`. The separate uniform measurement replaces **only** `p` with `1/t` for `E`, retaining the same complete O and same decoded V errors; it is not a teacher response. For flushed tokens `m=t−33`, define saved-FP32 residual `r_j`, source `x_j`, decoded `v̂_j`, and FP64 accounting defect `d_j=(r_j−r_{j−1})−(x_j−v̂_j)`. The before-O identity for the *actual* saved states is `Σ_{j≤m}p_j (v̂_j−x_j)=−Σ_{j<m}(p_j−p_{j+1})r_j−p_m r_m+Σ_{j≤m}p_j d_j`. Recent values contribute zero. This does not assert ideal arithmetic exactness or causal optimality.

Uniform V cancellation improves sharply in **both** layers, but selective V response worsens in layer 1 (+45.85%) and its full response worsens (+15.80%) on these same eight positions. Layer 1 uniform improves while selective and full worsen at validation (window,t) `(0,256),(1,128),(2,128),(2,256),(3,128),(3,256)`. Layer 0 uniform improves while selective V worsens at `(0,128),(1,256)`; full worsens at `(0,128),(0,256)`, although the eight-position total improves. The source/K offset and its inner product with V error are explicitly accounted for: a smaller V error alone does not determine full SSE.

Each layer has 917,504 chronological feedback value-coordinate updates across four streams. The shifted target is outside the source group's original `[min,max]` in 84,931 coordinates (layer 0; 38,293 below, 46,638 above) and 61,381 (layer 1; 30,361 below, 31,020 above). These count geometric clipping, not necessarily a saturated changed code after rounding. Largest observed residual magnitude is 0.43070221 in layer 0 and 0.19403589 in layer 1; source group step ranges are `[0.02400716,0.86263021]` and `[0.03312174,0.39127604]`. Per-window per-coordinate chronological minima/maxima, RMS distributions, range distributions, per-head peaks, and over-step counts are in `layer{0,1}-held-{0,1,2,3}.json`. Max actual FP64 target-addition/update defect from saved FP32 states is 1.49e−8 and 2.98e−8 respectively; weighted telescoping closes before O to 4.86e−17 or better. Largest exact SSE identity residual is 2.78e−17. These are a fixed-program diagnosis: clipping exists, but these receipts do not establish clipping as the cause of the layer-1 reversal; selective weights demonstrably defeat uniform cancellation on the held positions.

`summary.json` pins each window's source, O, paid-observer receipt and diagnostic SHA-256. To reproduce one window: `OPENBLAS_NUM_THREADS=1 python research/isa-quantization/value-feedback-selectivity/diagnose.py LAYER WINDOW`; the two loops over layers 0/1 and windows 0–3 are independent short stages. Then `OPENBLAS_NUM_THREADS=1 python research/isa-quantization/value-feedback-selectivity/summarize.py` checks original/feedback paid observer SSE and aggregates. All stages use existing frozen source arrays/images and CPU only.
