# Frozen balanced prefix: oracle affine-value readout capacity

**A discriminator of value-mixture capacity, not a new candidate.** The [one frozen balanced-and-centered rank-64 positive reader](../qwen-balanced-feature-reader/README.md) carries 64 stabilized per-feature value numerators `N_f` and denominators `Z_f` for the original 128-dimensional V stream. At each actual causal prefix, let `m_f=N_f/Z_f`. We give an **oracle** each query's true original complete two-head post-O output and let it choose arbitrary real *affine mixture* coefficients of these 64 `m_f`, separately for Q head0 and head1. Coefficients may be negative, arbitrarily large, teacher-dependent, different at every query, and need not follow the frozen exponential feature query weights. Both heads still share the exact same 64 carried value means and feed the original two O blocks. This is a strict relaxation of the existing **feature-weighted value-mixture readout**; it is **not** a bound against arbitrary nonlinear decoders of the complete prefix state, alternate value maps, or differently stored histories. Its oracle coefficients have no paid image or executable reader.

Across the original 8 train and 4 inspected-held 256-token source windows, the FP32-state **numerical SVD projection residual at the declared double-precision cutoff** is **.176292 train / .166595 held**, versus the actual frozen reader's **1.095124 / 1.093450**. Recomputing *the same finite-table state* with FP64 arithmetic yields **.164201 / .143703**. These numerical residuals remain about a thousandfold above the [paid KIVI G32/R32 4-bit causal cache](../kivi-causal-cache/README.md) **.000136612 / .000155355**, even after freely granting query routing and unbounded real affine coefficients. However, near-null singular directions and FP32 state noise make a numerical cutoff **not an exact-family certificate**. An FP32-resolved SVD cutoff moves the held diagnostic to **.291662**; the table, source states, rank and consumer are unchanged. This is a useful evidence-backed failure mode for this value-mixture grammar, not an information-theoretic impossibility for all programs on those stored bits.

## Frozen source, paid state and complete O metric

The source is the pinned Qwen3-0.6B BF16 checkpoint SHA256 `f47f71177f32bcd101b7573ec9171e6a57f4f4d31148d38e382306f42996874b` and fixture SHA256 `389e5f8c17ac151070b12094849f450130ab9c1684f51b402d59fd4e7ac2008f`, with the original 8+4 256-token reset causal windows. The immutable [replacement Q/K BF16 gamma image](../qwen-balanced-gamma/README.md) SHA256 `c8173158c88975e808804bb89a9e59b4cfa485a60f8d854fc4963ad89c830865` occupies the original **512 gamma bytes** and preserves actual source logits/probabilities/output bitwise on those windows. The [256-byte train-only FP16 balanced key center](../qwen-balanced-feature-reader/README.md) SHA256 `3e9fa69a8942b762f0cd041e6a70bfa0c7833957f0d960a6032b0775058cd6a2` and the original generic rank64 Gaussian FP16 table SHA256 `c79b3d345a0bfc6a1b2e4a6e8f04246e5b7750e885ae17f3eb36ad66d53d86f5` are unchanged. Original K/V/O source weights, both Q heads, K/Q norm and RoPE helpers match the same canonical consumer. None of the V map, O block, static model fields, rank, seed, precision or reader is refit here. The existing inference allocation is 33,280 B of FP32 prefix moments/log scales +16,384 B generic feature table +256 B per-model center =**49,920 B** at this group; replacement gamma is included in the common 1,573,376 B affected-group source state. The acceptance-only oracle's per-query coefficients and scratch QR/SVD matrices are **not** being called a 49,920-B reader.

Let `O0,O1∈R^(1024×128)` be the two actual source O blocks and `D=[m_1−m_0,...,m_63−m_0]∈R^(128×63)` at prefix `t`. The entire unconstrained affine-mixture *combined output* set is

```
(O0+O1)m0 + [ O0 D | O1 D ] β,     β∈R^126.
```

Every separate head mixture sums its 64 coefficients to one; the 63 non-anchor coefficients per head are free. Thus the exact least-squares distance from teacher combined output `y_t` to that affine set is the relevant **complete post-O** error, including O0/O1 cross-interactions and cancellation. `measure.py` QR-factorizes the source `[O0|O1]` once into a 256-coordinate *isometric output* chart and performs thin SVD of its **256×126** affine readout matrix per query. The tiny component of actual Torch FP32 teacher O output orthogonal to that chart is added back to squared error (summed orthogonal SSE across all 3,072 positions `1.93e−10`). This is not an independent raw-head V norm or a sum of separate head errors. Its held-oracle choices are **diagnosis** on already inspected held states, not parameters selected for export.

The actual prefix numerators, denominators and per-feature log maxima are updated with the **same FP32 arithmetic/order** as the frozen reader from independently decoded key gamma, center, table and BF16 source V. A second sensitivity state uses FP64 exponent/dot/update arithmetic on that very same fixed table and BF16 source producer; this is **not** a different feature family or an ideal infinite Gaussian kernel. At every prefix, each state's `m_f` is cast to FP64 only for the output projection/SVD. Tiny source-state deviations (`≤2.15e−6` max coordinate between actual and FP64 means over the complete experiment) can materially change an unrestricted oracle when its condition number is huge. The original frozen reader's and KIVI's actual scores come from SHA-pinned existing [`results.json`](../qwen-balanced-feature-reader/results.json) and [`KIVI results.json`](../kivi-causal-cache/results.json); they are not recomputed here.

## Measured projection and numerical scope

The two reported SVD thresholds are **declared numerical interpretations**, not extra candidate fits: `τ64=max(256,126)·eps(float64)·largestSingular` and `τ32=max(256,126)·eps(float32)·largestSingular`. The first retains more directions and gives the **smaller numerical projection residual**; the second shows what disappears at FP32-resolved relative scale. **Neither is an unconditional lower bound for unrestricted real affine coefficients:** truncating even one mathematically nonzero singular direction restricts that coefficient class and can overestimate its true infimum. Neither proves an exact rank or exact family error floor. The actual FP32 state can genuinely acquire extra affine directions from rounded numerator/denominator arithmetic that do not exist in the ideal token-affine value hull; an ideal algebraic rank cap cannot simply be imposed on those rounded coordinates. Numerical singular ranks and retained condition numbers are retained in every receipt; no threshold is selected from held quality. [`results.json`](results.json) aggregates each cutoff, source-state type, rank and condition; the 48 `*-chunk*.json` files retain per-position singular extrema and absolute squared-error receipts.

The numerical residual is not uniformly distributed across prefix lengths. On held `t≤64`, the FP32-state τ64 value is `.045041` and FP64-state `.025713`, while held `t≥65` is **`.207566` FP32 / `.183473` FP64** (each normalized on that subset's own teacher O energy). For **ideal arithmetic** each feature mean is an affine combination of the `t` source V tokens, so its two-head affine dimension is at most `2·min(63,t−1)`; when a short prefix's feature-weight rows span its `t` tokens, that ideal value-affine hull can exactly reproduce the prefix's teacher V mixes. The FP32 rounded carried N/Z state need not satisfy that exact token-affine cap. Apparent short-prefix residuals are therefore particularly sensitive to numerical state and SVD rank. At τ64, actual FP32-state SVD claims rank beyond that *ideal-only* algebraic cap for **248/256 held short positions** (and 496/512 train short positions), while the FP64 sensitivity has zero such held violations. The actual held retained-singular condition has median about `7.17e7` and maximum `2.25e11`; some FP64 finite-table states reach `1.74e13`. For later held prefixes the FP32 τ64 numerical rank is 126 at every position, but the median retained condition is still `5.58e5` and a few reach `7.70e8`. At τ32 its later numerical rank ranges **61–126** (median118), and later held projected residual rises to `.297822`. These facts delimit the evidentiary strength of an SVD-cutoff result rather than invite a post-hoc rank/threshold ladder. The strongly favorable KIVI margin appears at both reported numerical thresholds and for both state arithmetic variants; no exact universal lower bound is claimed.

A nonzero residual is specifically evidence about the **current mixture decoder grammar**: outputs built by separately affinely combining these 64 feature-value means through the original O blocks. An arbitrary nonlinear decoder could inspect the complete prefix moments and original current query, infer other aspects of the history and realize maps outside this affine hull; this study neither models nor excludes it. Likewise a co-designed V/O map or additional carried state changes the family and bytes. Strong paid KIVI retains a causal K/V representation and does not use this restricted value-hull grammar. The recorded numerical projection gaps suggest that a better query router alone is insufficient *within this grammar and reported arithmetic/cutoff*, but do not certify that statement for arbitrary exact real coefficients. Execution cost, coefficient magnitude and a rigorous exact gap remain separate questions. No new image or predictor is exported.

## Reproduction and bounded custody

```sh
cd /path/to/workspace/projects/kelana
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
PY=/path/to/workspace/data/fish-s2-pro/venv/bin/python
for panel in train held; do
  if [ "$panel" = train ]; then n=8; else n=4; fi
  for ((w=0;w<n;w++)); do
    for c in 0 1 2 3; do $PY research/isa-quantization/balanced-prefix-value-capacity/measure.py "$panel" "$w" "$c"; done
  done
done
$PY research/isa-quantization/balanced-prefix-value-capacity/aggregate.py
```

Each **64-query chunk command** completes under one minute on existing CPU1; loops are orchestration of independent bounded calls, not one monolithic computation. Forty-eight chunk receipts cover all 3,072 original query positions. Original fixture/checkpoint and all three paid images are SHA-checked; frozen actual baseline JSON files are pinned by SHA. No GPU, new capture, fit, seed/rank choice, feature table or native benchmark is involved. The parent owns shared synthesis/catalogue links.
