# Continuation contexts: exact frontier quotient and its obstruction

The current numeric live state is sufficient, **not always necessary**. The canonical target-independent directed reduction at a fixed search stage is a residual-program preorder: prefix `a` replaces `b` if **each legal complete continuation of `b`** has **some legal complete continuation of `a`** producing the identical *whole observed map*, at no greater total static bytes and no greater online work. One witness suffix is used for all inputs. Its choice may depend on the suffix being replaced, not on an input or teacher. Static bytes are the weight of the **union** of already-paid and suffix-used asset identities. Loss is evaluated on the final response, never on an invented intermediate decoder.

[`Kelana/ContinuationContext.lean`](../../../Kelana/ContinuationContext.lean) states and proves without `sorry`:

- `simulation_preserves_all_budgets`: every achievable `(behavioral error, static bytes, work)` budget of `b` remains achievable from `a`, for **any** terminal loss function on whole response maps. Mutual simulation therefore preserves every such Pareto frontier (`mutual_simulation_iff_budgets`).
- `simulation_iff_all_budgets`: the converse. If *all* terminal losses and *all* independent byte/work budgets are preserved in the directed sense, residual simulation is necessary. Isolate one suffix's whole response by a zero/one indicator loss and set the byte/work budgets to its costs. Thus mutual simulation is the **coarsest equivalence for this universal contract**; using only a particular teacher/loss can admit a coarser quotient.
- `same_suffix_profile`: numeric equality can be weakened to future union-charge profiles even for different paid-asset lists. `strictly_coarser_than_numeric` and `unrelated_paid_identities_can_merge` give strict witnesses.
- `shared_identity_separates`: two prefixes each paid one byte and have identical state/work, but the suffix reuses the first prefix's identity. Total static charges are one versus two bytes. Summarizing paid assets only by current size is unsound.
- `exposure_obstructs_quotient`: if a legal zero-work suffix observes the numeric state directly, simulation implies numeric-state equality. The possible number of irreducible states is unbounded; no grammar-independent strict compression theorem exists.

These are theorems about the declared complete finite-context grammar, not about a particular ISA, GPU cost or KL. `response` is a type parameter and must hold the full observation map on the intended reachable domain. The legal-suffix relation is indexed by numeric state; liveness, remaining length, boundary labels, shared constants and program restrictions must either be encoded in that state or legal relation. A suffix's used-static-identity set is explicit. The grammar currently treats it as suffix-dependent rather than state-dependent; a state-dependent use can be represented by expanding the finite suffix alternatives or generalized directly. Costs are nonnegative integer resource coordinates; additional coordinates repeat the same order argument. Preserving the set of feasible upper-budget boxes preserves the nondominated frontier, not just one scalar optimum.

## Constructing and using the quotient

For each stage and prefix, enumerate its legal suffixes; key the **whole response** and retain the two-dimensional antichain of `(union bytes, total work)` for each response. `a` simulates `b` iff each nondominated outcome of `b` is covered by a same-response outcome of `a`. Finite enumeration is a decision procedure, and `simulation_iff_all_budgets` says this test loses no universal frontier opportunities. Distinct suffixes can supply the matching outcomes: requiring the same instruction word is unnecessarily strong. Conversely, prefix maps with equal fibers but different numeric labels need not pass.

Naively this requires full residual-program enumeration, and can be exponential; it is a characterization **not an unconditional fast algorithm**. When the remaining grammar is small, compute these antichains backwards and memoize them; after each stage, use a cheap direct test or a sound lower bound before asking for the expensive exact simulation. A precomputed static charge profile may replace the paid-ID set: the initial paid sum plus the weighted overlap with every future suffix-use set determines every future union charge. Keeping only paid bytes does not. For an actual program cut, preserve the shared identity tag until its future incidence is known.

[`search.py`](search.py) is a deterministic, standard-library witness. Run `python3 research/isa-quantization/continuation-context/search.py` from the Kelana root; it regenerates [`results.json`](results.json) in under one second. Four numeric states and all four paid subsets of two one-byte IDs give 16 nodes. Two suffixes yield complete two-input Boolean response maps: `bit` exposes parity and reuses identity `a` at one work unit; `zero` returns zero at two work units. There are **8** mutual-simulation classes. The script compares the actual Pareto fronts for every one of the four Boolean teachers within each class. This is a finite illustration only; the Lean theorem is independent of those four teachers and machine sizes. The same script explicitly checks the shared-ID asymmetry (paid `{a}` versus `{b}`: one versus two total bytes for `bit`). No planted-compression prevalence or native speed claim follows.

The useful decision rule is therefore contextual: if the live suffix can expose a register value cheaply, keep the numeric label; if every legal suffix erases or cheaply remaps it, the residual quotient can identify it. The obstruction is not the representation's fibers but the separating power **and paid asset reuse** of its legal future programs.
