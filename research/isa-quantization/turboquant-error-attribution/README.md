# Frozen full-layer TurboQuant K/V and QJL-residual error attribution

**Result.** On the original Qwen3-0.6B layer0 **16 Q / 8 KV head, 128D, 256-token causal, full original O** observer, the fixed paper-port TurboQuant K3=(MSE2+QJL1)/V2 image has large **key-score-only** complete-O error. The source-preserving coupled Q/K gamma gauge reduces it substantially, but the *already fixed* Gaussian QJL residual correction makes the complete-O response worse than its own MSE2 coarse-score route in **every one of the eight train and four inspected-held windows**, with V and the image's MSE2 codes unchanged. This is retrospective analysis of two actual paid images, **not** a new encoded coarse-only candidate, a parameter choice, a proof that QJL is bad for other random draws, or a full-model TurboQuant evaluation. K-only/V-only counterfactuals and the nonlinear interaction identify what failed; unbiasedness over random sketch draws is not a per-draw softmax/O error guarantee.

## Frozen source, identity and algebra

The [original paper-defined CPU port](../turboquant-causal/README.md) and the [one paid coupled-gamma port](../turboquant-coupled-gauge/README.md) already carry actual independent packed causal K/V images, the same FP32 196,624 B program, source and full-layer O weights. The latter replaces exactly 512 B of BF16 Q/K gamma in the same-size 12,583,424 B source image and re-encodes only K; original V cache bytes are identical. Its source Q·K logits/attention/O match the original uncompressed teacher exactly before cache insertion; both arms use post-RoPE BF16 inserted K. No source, codes, radii, sign bits, program or gamma fields were changed here. `diagnose.py` independently reads each frozen image and program through the donor's decoder, checks the paid hashes and **all** source-derived indices, signs and norms, and uses the original Qwen causal mask, 16 Q-to-8 KV map and 1024×2048 O. Receipts refer to the original images instead of copying them. The prior paper [Algorithm 2](https://arxiv.org/html/2504.19874v1#S3) uses an asymmetric Gaussian-sign QJL *score estimator*, not a general materialized residual-key reconstruction.

For a given window, let `P*` be the exact teacher causal probabilities, `Pq` the frozen MSE2+QJL logits' probabilities, `Pc` the same frozen MSE2 coarse-code logits **without** QJL correction, `V*` original value vectors and `Vhat` the actual frozen decoded V. Let `O(P,V)` concatenate the 16 shared-KV-head attention outputs and apply the original O. Define `T=O(P*,V*)`, `K=O(Pq,V*)−T`, `V=O(P*,Vhat)−T`, `I=O(Pq,Vhat)−O(Pq,V*)−O(P*,Vhat)+T`. Then the paid response error is **exactly the signed-vector sum** `K+V+I`. `I` includes changed attention×value errors and is not independently attributable to just one cache. Squared error is `||K+V+I||²/||T||²`: all **six Gram terms** are required. `Pc` counterfactuals change the score reader only; no coarse-only cache/program was compiled. Teacher values in K-only and teacher probabilities in V-only are *free diagnostic oracles*, **not paid candidates**.

The table sums squared numerators and teacher squared denominators over all positions, heads and windows before dividing. `QJL both` is the frozen complete paid result; `coarse both` is the counterfactual with the same stored coarse K codes/radius and V but no QJL score term. `K-only`, `V-only`, `I²`, `coarse K-only` are relative squared errors/effect energies. Mean Q-head KL is averaged over all 16 heads, 256 positions and windows. The current diagnostic batches O reductions, with up to 1.12e−7 windowwise relative-squared drift versus the frozen per-query reader; it reproduces the teacher bitwise and tests `K+V+I` directly (max entrywise residual 2.39e−7). ## Byte and work boundary

Both original and gauged **actual** images at256 carry 8 KV heads ×256×(K 56 B +V 36 B)=**188,416 B**, plus shared three FP32 128² maps and four FP32 centroids **196,624 B**, combined **385,040 B**. Source model weights and gamma allocation are common (12,583,424 B); gauged gamma physically replaces original fields, not a 512 B increment. The coarse-only *hypothetical projected compact format* could drop each K's 16 B QJL signs and 4 B residual norm and the shared 65,536 B FP32 Gaussian projection while retaining K 32 B MSE indices+4 B source radius and V 36 B: 8×256×(36+36)=**147,456 B dynamic**, two rotations+centroids **131,088 B**, sum **278,544 B**. There is **no actual separately compiled image or acceptance result at that projected rate**; it is a storage consequence of omitting already read fields, not a measured equivalent-rate compression claim. The QJL reader also uses an extra 128×128 Gaussian query transform and 128 sign products per earlier K; coarse-score diagnosis omits that work, not the MSE route, causal softmax, V decoding or O. Offline preparation, transient full probability/decoded arrays in this attribution script, online work, and actual resident bytes are different axes. No native latency or full-model loss follows from these CPU responses.
