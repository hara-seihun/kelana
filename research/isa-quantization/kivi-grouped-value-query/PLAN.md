# Frozen query discriminator (declared before numerical runs)

One implementation, no search: one CTA per KV head, 128 lanes, two Q heads sequentially. Read the original K chunks and recent BF16 keys from the five-byte-header dictionary image; calculate conventional FP32 Q·K scores in token order, stable max/subtract/exp/sum softmax, with the original KIVI2 decode and original full O. For each Q head, after softmax, zero per-domain per-record FP32 probability masses, traverse the quant and recent positional u8 references once in token order and add each probability to its own typed record mass. Then traverse quant dictionary entries in first-occurrence order, decode each 48-byte per-head V and FMA it into the 128-coordinate mix weighted by that head's mass; traverse recent entries analogously at 256 bytes per head. Two Q heads share dictionary bytes but never mass. Finish eight O partials in the unchanged second kernel. Control: same source image, direct per-position V reference/dictionary dereference, conventional position-ordered FP32 V FMA, same K/score/softmax/O. No expanded K/V matrices or GPU launch. CPU computes both arms independently from actual immutable dictionary images on every before-query causal state, fixed source Q/O and teacher; immutable image generation is an input replay, not a new fit or a quantizer. Source/fixture identities, complete FP32 output difference and original-teacher normalized SSE are acceptance. Compile both complete gfx1151 kernels and count real code/resources, explicit allocations, reference/address and reduction work. A negative numerical or resource result ends this discriminator.
