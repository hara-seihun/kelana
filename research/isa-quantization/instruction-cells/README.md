# Let an instruction choose the quantization cells

An integer square followed by a shift gives a useful eight-cell quantizer for a small SiLU gate/up response. On 27 of 32 independently drawn three-output teachers it has lower complete-domain response error than the best producer in a searched affine multiply/shift grid, with the same eight-entry observer and two producer instructions. It loses on all 32 linear and all 32 unstructured controls. This is a finite response construction, not a claim about a trained model or kernel speed.

## The cell map and its complete cost

The dynamic input is an unsigned five-bit activation code `x ∈ {0,...,31}`. The target has three output coordinates

```
y_j(x) = SiLU(g_j*x + b_j) * (u_j*x + c_j),  j=0,1,2.
```

Each teacher independently draws its twelve real coefficients from the ranges in [`search.py`](search.py). The encoder is **not free**: `q(x) = (x*x) >> 7` needs an unsigned 32-bit integer multiply and logical right shift. It produces all eight codes, with changes at `x = 12,16,20,23,26,28,30`. The consumer indexes one row of three fitted FP16 outputs; no original gate or up activation is recovered. One concrete layout uses eight aligned eight-byte rows, each holding three FP16 values and two padding bytes. That costs **64 model bytes**, not 48. The shared observer must also form `q<<3`, add the table base, fetch eight bytes, and extract three FP16 values. Conversion to FP32, if required by the next consumer, adds work. The input code, table pointer and output registers are live dynamic state. Table construction evaluates all 32 teacher states and fits three conditional means per cell; this is offline work and 96 teacher-response queries per teacher, not a free oracle at deployment.

[`cells.s`](cells.s) assembles on gfx1151. Its producer takes 12 bytes of instruction text, two data instructions, plus a four-byte `s_endpgm` in the stand-alone example. The matched affine seed-0 producer has the same sizes. The table address and fetch above have **not** been assembled or timed; their equal cost in this comparison follows from using the same eight-row layout for both arms, not from calling lookup free. A real kernel must pay table placement, loads, code extraction from its input representation, scheduling and any next-stage conversion. Neither producer is charged only its static bits while the other pays runtime work.

## The comparison

The affine control searches every distinct partition obtained in the declared grid

```
q(x) = (a*x+b) >> s,
2 <= s <= 10, 1 <= a <= 256, 0 <= b < 2^s,
q(31) <= 7.
```

It searches 797 distinct partitions, fits the same three FP16 labels to every one, and keeps the best response. It even gives the affine family a free fused multiply-add for nonzero `b`; some of those constants might take additional instructions or literal bytes on gfx1151. This favors the control. The seed-0 winner uses `a=31,b=0,s=7` and really is a two-instruction 12-byte producer, as assembled beside the square program. Both have the same 64-byte table and the same observer. The affine search has no charged codebook or hidden fit-query advantage. For other seeds, model-specific instruction immediates belong in the paid program text; the 797-grid score is a generous distortion control, not an assertion that every grid point has the seed-0 cost.

For another comparison, dynamic programming fits the best **eight contiguous intervals**, with arbitrary FP64 vector labels and seven independently placed cuts. This is a stronger rate-only control, not an equal-work program: locating seven arbitrary thresholds and storing their values is omitted from its reported error. It is not a bound over noncontiguous partitions. The experiment scores every one of the 32 reachable inputs, normalizing squared error by the centered teacher-response energy over those inputs. It rounds the executable tables to FP16 *before* scoring.

| 32 teachers | Square wins against affine | Median square relative RMS | Median affine relative RMS | Median unconstrained-interval relative RMS |
| --- | ---: | ---: | ---: | ---: |
| SiLU gate/up | 27 | .11331 | .13387 | .10891 |
| Linear, random slopes and offsets | 0 | .24104 | .12109 | .12109 |
| Unstructured independent Gaussian response | 0 | .88355 | .82430 | .72794 |

Seed 0 makes the comparison inspectable. Its square cells cut at `12,16,20,23,26,28,30` and score `.1193116`. The best affine program `(31*x)>>7` cuts at `5,9,13,17,21,25,29` and scores `.1375294`. Seven arbitrary cuts at `10,15,19,22,25,28,30` score `.1129256`, before FP16 rounding or paying for threshold selection. The square does not magically beat a freely located quantizer. It gets much of that nonuniform allocation through two integer instructions and no fitted thresholds.

The 32 SiLU coefficient draws and the two opposing teacher families are generated by fixed seeds in `search.py`; no candidate is planted in a teacher. The examples favor a convex positive response domain. They do not estimate prevalence across trained activations. Changing the input distribution, starting from signed A8, crossing zero, coupling channels with real down weights or quantizing later state may reverse the ranking.

## Reusable search reduction

For a proposed integer program `P`, enumerate its reachable cell labels `q_i=P(x_i)`. For any target vectors `y_i`, the best real squared-error continuation assigns each label `c` the mean of its fiber. The conditional-mean identity gives

```
SSE(P) = sum_c sum_{i:q_i=c} ||y_i - mean(y | q=c)||².
```

The closest FP16 value to each mean is independently optimal among FP16 table entries. Thus the script screens a program by its *complete* producer-plus-observer response, not by its resemblance to a hand-chosen scalar level grid. Distinct programs with identical fibers share the real/FP16 fit and may be deduplicated for response search, but their instruction counts, numeric labels, address costs and continuation legality cannot be deduplicated. `search.py` keeps one representative of each affine partition for this one common table observer; a later ISA search must retain the cheapest valid realization and any numeric-label-sensitive consumers. This also avoids the trained eleven-state carrier's mistake: it measures the error of every induced collision against the actual target before treating a small state count as a success.

The finding extends the fixed candidate-menu quantization search in [the mathematics note](../../quantization-discovery/MATHEMATICS.md) by making **ISA-produced cell geometry** a search variable. The conditional-mean formula itself is standard least squares, not a new theorem. The next real-weight experiment should enumerate producer-reachable quantized inputs for a small SiLU/down region, rank paid instruction cell programs by their complete output response, and reject any carrier whose collision floor already exceeds the response budget. It should preserve the full code and scale state whenever the trained-output capacity bound requires it.

## Reproduce

From this directory:

```sh
OPENBLAS_NUM_THREADS=1 python3 search.py
llvm-mc -triple=amdgcn-amd-amdhsa -mcpu=gfx1151 -filetype=obj cells.s -o /tmp/instruction-cells.o
llvm-objdump --disassemble --mcpu=gfx1151 /tmp/instruction-cells.o
```

[`results.json`](results.json) contains all coefficient draws, fitted scores, program witnesses and interval cuts. The Python run uses NumPy, one BLAS thread and bounded CPU work. Python float64 teacher evaluation and FP16 label rounding are distinct from ideal exact arithmetic and native GPU floating semantics. The assembled code certifies producer instruction legality, not the observer's latency or an end-to-end gain.
