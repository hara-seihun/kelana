# Whole-GQA-selected coordinate programs

**Decision.** [The initial full-group failure](GROUP.md) carried 64 angles fitted only to Q head 0's first tile. Here every candidate fits **both complete Q heads and their shared K head** to full Q4, and its angle is selected by *complete train causal GQA attention KL* (two heads, real shared K; combined O error also reported). Two finite structural families include identity. The all-pair-common angle family selects **identity** on train. A gamma-balanced family allows a common angle only on the 44 pairs with both Q and K gamma-ratio log magnitudes below `0.5`; its train-selected `+π/8` improves mean KL **0.00785420 → 0.00737191** over its same-fitter identity. On the separate, previously inspected held windows this reverses: **0.00901992 vs identity 0.00808945** (and vs the earlier stronger matched scalar Q4 **0.00779049**). Its combined V/O error also worsens: **0.00298135 vs identity 0.00212020** and stronger scalar **0.00204247**. Thus the changed selection objective can find a train gain once gamma-outlier pairs are excluded, but there is **no held complete-group survivor in these two families**. Do not infer that all 5^64 pair assignments fail; no GPU reader is proposed here.

The families are mathematical program restrictions, not a widening sweep of unrelated constants. `global`: one angle from `[0,-π/8,+π/8,-π/4,+π/4]` for all 64 pairs. `balanced`: the same single angle on exactly those pairs for which `max(|ln |γQ_y/γQ_x||, |ln |γK_y/γK_x||) < 0.5`, identity elsewhere. This filter is a predeclared guard against distorted `Γ⁻¹RΓ` maps on highly unequal gamma coordinates. It uses existing gamma fields, **not validation labels**. It selects 44 pairs on this pinned model. The five angle codes, including zero, are exhaustively evaluated on the two 256-token train windows under the same quantizer, then the lowest *two-head causal KL* is replayed on the separate two held validation windows. No held loss enters selection. Each candidate fits all `384×8` Q/K row×group records using the same three-init/three-sweep covariance Q4 fitter; unlike [the previous group study](GROUP.md), none receives a special stronger first tile. This equalizes the within-family image fit. The first Q tile's FP16 scalar signs pass the constrained-format check in every candidate; three redundant sign bits per pair store each five-way angle label **within** the 208,896-byte group payload. Images are independently decoded before replay. The identity image is a conventional affine Q4 image; its unchanged sign bits allow a scalar Q4 reader to omit metric and label machinery altogether.

## Static bytes, prepared state, and actual reader work

Both candidate and ordinary scalar Q4 store **384 rows × 8 records/row × 68 bytes/record = 208,896 static Q/K payload bytes**. They retain no BF16 Q/K tail. Five-angle vocabulary and gamma-balance predicate are fixed program logic; all model-specific angle choices are stored in first-tile FP16 sign bits. Existing BF16 Q/K gamma, V and O are unchanged on both sides. No separate persistent metric array is included in this static-byte claim.

The **actual Python replay** decodes the 208,896-byte image into 384×1024 FP32 Q/K weights (**1,572,864 decoded bytes**, a transient/common memory choice also made by the scalar reader) and retains a decoded `uint8[64]` angle array (**64 additional bytes**). It restores the canonical signs of three FP16 fields per pair before decoding the first Q tile; extraction requires three sign-bit reads and code assembly per pair, and restoration uses three sign masks per pair. `metric_norm` does **not** keep precomputed model-specific metric arrays: for every call it constructs a float64 pair transform/inverse from angle and existing gamma for each of 64 pairs, obtains three FP32 quadratic coefficients by conversion, and evaluates those terms on the FP32 BF16-rounded activation. It allocates a 256-element FP32 norm accumulator (**1,024 bytes per active call**) plus ordinary activation temporaries. The simple replay normalizes shared K twice, once per Q-head call, so it performs four 64-pair metric constructions per 256-token window; an optimized reader would share K and do **three** normalized head vectors. This is additional *work and transient state*, not a free meaning for equal serialized bytes.

An explicit alternative native/prepared reader would retain three FP32 symmetric metric coefficients for each of 64 pairs for Q and K: `2 × 64 × 3 × 4 = 1,536 additional live bytes` plus the 64 decoded angle bytes, i.e. **1,600 bytes** beyond common decoded weights/gamma. Coefficients derived from gamma and angles require preprocessing even if not persistently serialized. For the balanced winner, 20 identity pairs could use ordinary norm squares and avoid their coefficient loads; a compact 44-pair coefficient array needs `2×44×3×4 = 1,056` bytes plus labels, but still needs a 64-position schedule/mask. No claim that such a native kernel or its memory/register cost was measured. If the metric table were persistently stored, its full precision **1,536 bytes** would also increase static model bytes; the earlier FP16 estimate of 768 bytes does not describe this replay's FP32 coefficient arithmetic and is only an untested lower-precision alternative. The selected global identity is special: compile it to plain Q4/RMSNorm with **no extra metric state**, while the balanced nonidentity requires this added work/state. These costs preclude a speed claim even had the held behavior survived.

To rerun the finite family, invoke **one candidate per sub-minute CPU command**, with one BLAS thread. Set `FAMILY` to `global` or `balanced` and `CODE` to each of `0,1,2,3,4` in separate calls; after all five receipts exist, use `--select` to choose from *only* train receipts and replay that winner on held:

```sh
cd /path/to/workspace/projects/kelana
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 /path/to/workspace/data/fish-s2-pro/venv/bin/python research/isa-quantization/transported-norm/global.py --family FAMILY --candidate CODE
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 /path/to/workspace/data/fish-s2-pro/venv/bin/python research/isa-quantization/transported-norm/global.py --family FAMILY --select
```

Each invocation is bounded below one minute; do not run all candidates in one attended shell command. Input data, search and the decision are all local to this study. A broader adaptive 64-pair program or a different quantized carrier remains open.
