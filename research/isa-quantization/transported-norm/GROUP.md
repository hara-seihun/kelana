# Full affected GQA Q/K group: same-byte Q4 continuation

**Bounded negative.** The sign-embedded transported coordinate [improves the held complete observer while only Q head 0's first 128×128 tile is Q4](SIGN-EMBEDDED.md), but that local advantage **does not survive this matched full-group Q4 construction**. Quantizing *both* complete 128×1024 query heads and the entire shared 128×1024 key head gives held GQA mean causal attention KL **0.00942192** and combined V/O relative squared error **0.00316834**, worse than the **same-208,896-byte** scalar Q4 control's **0.00779049** and **0.00204247**. On the 512-token train fit, the respective KL values are **0.00875923** and **0.00752592**. This rejects the presently serialized five-angle choices and matched full-group row-grid reader; it does not bound all train-selected coordinates, other quantizers, mixed-precision formats or the entire model. The decline appears already on train, so more held windows are not a remedy for this candidate. No native/GPU benchmarking is warranted on these images.

## Complete byte/work ledger

[`group.py`](group.py) stores three projection matrices in the fixed order **Q head 0, Q head 1, shared K head 0**. Each matrix has 128 rows × 1024 inputs. Every row is partitioned into eight adjacent 128-input groups, each a 68-byte record: 64 bytes of packed affine Q4 nibbles (lower nibble first), FP16 origin and FP16 step. Thus `3 × 128 × 8 × 68 = 208,896` model-specific group payload bytes on **both** sides, compared with the source BF16 group's `3 × 128 × 1024 × 2 = 786,432` bytes. No original BF16 Q/K tail is retained in either candidate. The scalar control's first head-0 tile is the seven-initialization/five-sweep zero-angle affine grid fitted on the same 512 train tokens as the earlier local study. There are **3,072 row × group records**; the first 128 use that stronger matched fit and the other **2,944** use the common three-initialization/three-sweep group quantizer. The coordinate's first 128 records are the earlier train-selected five-angle Q4 image; its 64 label codes occupy the three constrained FP16 sign bits per pair within those records. Each remaining record in both sides uses exactly the same quantizer algorithm and the same train-token 128-input covariance; the coordinate quantizes transformed `Γ⁻¹RΓ` query weights and corresponding shared-key weights, whereas the scalar side quantizes original Q/K weights.

The coordinate full-group file is [`q4-gqa-coordinate.bin`](q4-gqa-coordinate.bin), the control is [`q4-gqa-scalar.bin`](q4-gqa-scalar.bin); [their SHA256s and all panel scores](results-group.json) are recorded. The coordinate reader extracts and restores the first tile's embedded label/sign bits before affine decoding and rejects invalid labels; it reads no separate table. The 64 choices were selected only on the original 512 train positions; all remaining FP16 scales/origins and nibble codes were likewise trained on those positions. Both full-group images preserve the Q/K normalization gamma fields, V/O projections and all unaffected model data. Their equal static-byte claim is for the affected Q/K projection payload (and unchanged surrounding fields), **not** equal runtime cost: Q/K dot work is the same shape, but the coordinate has additional sign extraction/restoration and three transported 64-pair quadratic RMSNorm evaluations per token (two Q and one shared K), coefficient preparation/loads and altered cache coordinates. This CPU implementation computes K's norm twice across query heads; a fused reader could reuse it. Neither is a measured native kernel.

## Causal replay and scope

After reading each **saved** 208,896-byte image, the script independently decodes all three full Q/K matrices. It projects four 256-token original layer-input windows (first two train and first two disjoint validation windows), BF16-rounds Q/K/V projection outputs and normalized vectors, uses the original BF16 gamma and `1e−6` epsilon, RoPE position phases, FP32 causal log-softmax/value mixing and original O blocks. The coordinate carries both query heads and their one shared key across the whole group; the scalar control uses the ordinary norm. Teacher-to-candidate attention KL averages over both query heads; V/O relative squared error compares the **sum of both head contributions**, not the entire model's hidden state. Head-0 held KL is **0.01381125** vs scalar **0.01145644**; head-1 held KL **0.00503258** vs **0.00412454**, so the negative is not hidden by a good head masking a bad GQA peer. The real-coordinate theorem remains exact for unquantized weights; quantizing both Q/K complete matrices changes the reachable finite arithmetic and the fitted error geometry. This is an isolated layer-0 attention subgraph, not a whole-model NLL result.
