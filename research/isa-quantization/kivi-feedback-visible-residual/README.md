## Frozen arithmetic and chronology

For query `t` in 1…256, `m=max(0,t−33)` V records have been quantized **before** this query. The outstanding edge is from one-based source token `m` toward `m+1`. For each KV head, independently read its actual 128-coordinate FP32 donor residual after flush `m` and before the current query's flush; if `m=0`, use zero. The unchanged K2 cache produces the 16 per-Q-head scaled dot-product FP32 softmax vectors. The unchanged feedback V cache, including untouched BF16 recent vectors, produces the ordinary mixed V by FP32 Torch `bmm`. For each Q head `a` using KV head `floor(a/2)`, form FP32 `p[a,m−1] * residual[floor(a/2)]`, then FP32 add this 128-vector to its **ordinary** mixed V. At `m=0` the correction is zero. Flatten 16 corrected mixed heads and apply the original full 1024×2048 BF16-decoded O with the owner's FP32 Torch reduction; compare with its original saved FP32 teacher in float64 squared error. Each shared KV residual is weighted by **two separate source probabilities**. There is no after-query residual, lookahead source, source-index bank, alternate O, or encoder change.

The already resident eight residuals cost **4096 B** per sequence. Feedback cache plus residual remains **308864 B peak / 253952 B final**, original K2/V2 **304768 / 249856**, lower-state V34/delay2 **308096 / 253184**, K2/V4 **361856 / 307200**. The changed reader pays up to **4096 B residual reads/query** shared across GQA heads, 16 source-probability accesses, 2048 FP32 probability–residual products and 2048 FP32 adds, plus correction/mixed temporary vectors (each 2048×4 = 8192 B if materialized). Softmax normalization, source-probability extraction, FP32 attention/reduction, normal K/V decode, unchanged full O and shared static source weights remain real costs; no added persistent index because chronology determines `m`. Neither score nor memory bill claims GPU/native throughput. Source NPZ, logs and replay-expanded FP32 matrices are offline custody/scratch, not cache state.

**Cross terms, not boundary-only norms.** For ordinary full-O output `y`, teacher `z`, and actual rounded output difference `d = O_FP32(FP32(mixed + p_m*r)) − y`, each row exports `ordinary_sse=||y−z||²`, `cross=2⟨y−z,d⟩`, `correction_sq=||d||²`, and `sse=||y+d−z||²` (float64 accounting). These terms retain K/source-offset, all feedback interior/defect and cross-head contributions through common O. Train cross −2.734963045 plus correction² 1.424085068 gives ΔSSE −1.310877977; validation −1.117708390 + .617029990 gives −.500678400; layer-0 −.005345011 + .005412761 gives **+.000067750**. Rounding means `d` is measured from both actual O reductions rather than presumed exactly linear. Exact numbers and output SHAs are in [results.json](results.json) and per-window receipts.

## Immutable donor correspondence and replay

[`replay.py`](replay.py) independently walks every query's arrived BF16 K/V, both packed event kinds, K source fields/digits, V source group extrema/FP16 fields, shifted target digits and FP32 recurrence. It verifies **every** pre/post donor cache byte count/SHA and pre/post residual SHA (all 256 phases × 8 heads × 16 windows), original source and feedback event/final bytes, and the ordinary reader output SHA against its existing successful result. Contextual NPZ Q/teacher/O and all array hashes come from the [contextual-feedback owner](../contextual-value-feedback/README.md); retained layer-0 Q/teacher/O and baseline image hashes come from the [feedback owner](../kivi-value-error-feedback/README.md) and its existing snapshot owner. No unchanged arm is re-scored. Importing the contextual owner's `replay.py` decode/field verifier reuses its independent-of-builder arithmetic rather than the producer; this new script owns the chronology, residual phase, output and correction. [aggregate.py](aggregate.py) SHA-pins both unchanged summary receipts, each original per-window result and donor manifest; individual source NPZ SHA and O SHA are recorded in the contextual receipts. Source-program descriptions are those SHA-linked owners; no extra inference model fields exist.

Each retained `*-t128-prequery-residual.f32` / `*-t256-prequery-residual.f32` is exactly **4096 B**, KV-head-major eight contiguous 512-B blocks; each block is 128 little-endian FP32 coordinates in native V order. The matching row identifies the file, whole-file SHA, and each head's pre-query residual SHA. At other queries the program reconstructs these bytes from the preceding verified after-query recurrence, so the complete correspondence is phase-checked without 3,072 additional permanent images. Each per-window JSON has `t,m`, eight pre-query cache/residual hashes, ordinary/corrected output SHA and exact SSE accounting. The eight retained layer-0 rows also identify the unchanged baseline image hashes. `results.json` contains donor/source identity hashes and pooled controls.
