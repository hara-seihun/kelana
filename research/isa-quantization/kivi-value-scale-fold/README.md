# One train-only power-of-two V/O fold for full-layer KIVI2

**Result: scoped negative.** On Qwen3-0.6B layer0, with the original 16 Q / 8 KV heads and complete original O, a single predeclared train-max V/O channel gauge increases KIVI K2/V2 G32/R32 complete-O relative squared error at **exactly the same 304,768 B peak cache**: train **.003239980806 → .003315938944** (+2.344%) and inspected held **.003124372694 → .003222022150** (+3.126%). No different exponent, grouping, bit rate, calibration statistic or held-selected arm was tried. This refutes a gain for *this fixed fold and observer*, not diagonal smoothing or KIVI generally. The donor is the [paid full-layer KIVI2 image](../kivi-two-bit-causal/README.md), which remains immutable.

## Source-only choice and physical folding

For each original 128D BF16-projected V head, use only the 8×256 **train** source tokens. Within each of its four original contiguous G32 value groups, let `M_d=max_train |V_d|` and `M_g=max_d∈g M_d`; choose the largest nonnegative integer `e_d` with `2^e_d M_d≤M_g` (equivalently floor log2 of the exact ratio), with deterministic exact binary comparisons and `e_d=0` for a zero channel. All 1024 channels were nonzero; **792 e=0, 219 e=1, 13 e=2**. The transformed training channel extrema remain within the original group maximum; this envelope alone is *not* a realized response-error guarantee. The parent's [range-gauge theorem](../value-range-gauge/README.md) proves optimality of the corresponding continuous error box, a fourfold rounded-box bound including fixed K error, and an exact counterexample where the stronger box bound accompanies worse actual min/max output. These fields are offline provenance, **not** a transmitted 1024-element exponent table.

[`prepare.py`](prepare.py) loads the pinned original BF16 layer0 V (1024×1024) and O (1024×2048) tensors, multiplies the *actual physical* V row `(KV h, d)` by `2^e[h,d]`, and the corresponding O input column `(Q 2h,d)` and `(Q 2h+1,d)` each by `2^-e[h,d]`. No changed channel order, runtime scale, key transform, gamma, group fields or extra instruction is needed: the new [`replacement-v-o.bf16`](replacement-v-o.bf16) is **6,291,456 B**, SHA256 `cc4be5ba10f0b85ad04518a58015a1429acfff459c9fc14287dbf1f7c8021f60`, replacing the same-size original V/O share of the common **12,583,424 B** source Q/K/V/O/gamma image (**zero incremental static bytes**). Every individual BF16 weight scaling and inverse multiplication is bitwise exact with no overflow/underflow. `source-fields.json` records extrema, group maxima, all exponents, original tensor hashes and the replacement image hash; only the image is used at inference.

[`source.py`](source.py) independently decodes that paid BF16 image, runs the actual producer `x @ Vnewᵀ` through the canonical BF16 rounding and original causal Q/K probabilities, applies the folded full O, and compares against the donor original. On **all 8 train +4 inspected-held windows**, transformed BF16 V equals original BF16 V times `2^e` bitwise, and the entire **uncompressed full O output is bitwise identical** to the original teacher. The 12 `*-source.json` records expose exact equality and reference squares before any cache encoding. This is a genuine source-coordinate change, not an output-target substitution.

## Actual paid causal cache and independent replay

The original KIVI2 chrono contract stays fixed: keys are post-RoPE BF16-arrival, per-channel K2 min/max over32 arrived tokens, values per-token V2 min/max within the **same original four contiguous32-channel groups**, FP16 origin/step and nearest-even codes, BF16 recent K/V32; flush after the current query. `build.py` copies all original K flush records **byte for byte** at their original event positions, repacks only folded V events from the current arrived BF16 source, and emits full paid per-head causal final images and before/after prefix SHA256s. The 12×8 immutable final images and chronological logs are in this directory; logs are audit evidence, not another retained cache. `replay.py` imports **no builder quantization/packing routines**: it decodes fields/digits directly, checks each original K event byte identity and all V decisions from only available source tokens, all paid prefix hashes, log exhaustion, final-image identity, GQA routing, causal softmax and the **folded physical O**. It checks equal teacher denominators to original KIVI2. The source O equality proof ensures the comparison is to the same uncompressed map.
