# Latest ternary scale-direction extrapolation: no selectable complete-model gain

The selected Qwen3-0.6B complete `fresh-duration32` ternary image is the endpoint of sixteen new whole-model scale-only gold-loss steps from `fresh-duration16`. This experiment asks whether **one more half of that same FP16 scale update** improves the 197-matrix model at its paid physical rate, without training another weight or changing trits. It is a fixed coordinate test, not a search over coefficients: for every scale word, round `1.5 * latest - 0.5 * predecessor` to FP16. Every code, Hadamard sign, shape and norm is unchanged. The saved candidate has the same 128,678,649 raw bytes / 1.727086 BPW; 2,715,064 FP16 scale words differ from the predecessor. The existing fresh-duration training text is not reused for evaluation.

A new 16-window, 4,080-prediction WikiText-2 test fixture was frozen first with seed 2026092441, excluding **all previously recorded test intervals** including the fresh-duration32 panel. First eight windows select against the unchanged latest image, last eight are withheld. Each comparison evaluates the entire BF16-expanded packed model and 255 next-token targets per window:

| Image | First-eight selection NLL | Withheld-eight NLL | Complete exact 16-KiB-code/256-row-scale physical bytes | Physical BPW |
| --- | ---: | ---: | ---: | ---: |
| `fresh-duration32` | **4.656302** | 4.507242 | **122,975,884** | **1.650544760** |
| fixed 1.5× direction | 4.657089 | 4.506743 | 122,976,108 | 1.650547766 |

The extrapolation **loses 0.000787 nats on selection**, so it is not selected. Its withheld improvement is just **0.000499 ± 0.001339 nats** over eight windows (4/8 favorable), at **224 more paid bytes**. It does not establish a held improvement either. This is a measured negative for reusing this short latest update direction as a fixed 1.5× step, not for other optimization directions or longer recovery. The earlier 1.5× win extrapolated much more distant `expanded-scale128` → `expanded-scale384` checkpoints on different text; it does not transfer as a rule to the small latest update. Future quality work should use **new training text and matched full-model scale-only versus coupled code/scale updates**, chosen on new selection text; another scalar extension of this direction is lower priority. Qwen3.6 MoE still requires actual routed-producer-based complete-image quality. No packed reader, native inference time or serving change was measured.

The candidate's complete 256-row scale pages and 16-KiB code pages were independently decoded against all 197 original packed matrices; both source and candidate physical rates include directories, flags, scales, signs, shapes and norms. The price differs because scale page entropy changes, not codes.
