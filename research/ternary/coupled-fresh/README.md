# Fresh complete-model trit/scale comparison at paid rate

Starting from the complete 197-matrix Qwen3-0.6B `fresh-duration32` image, eight gold-loss steps on previously unused expanded-train rows 488–495 (256 tokens/window) compare **matched** scale-only recovery against scale recovery plus at most 64 gradient-favored trit flips per matrix in layer 14's seven projections. The code arm changes exactly 448 trits; both arms train all FP16-rounded scale providers with the same Adam learning rate .0001, windows, step count and train-only checkpoint criterion. The code arm uses the existing `tune.py` straight-through latent, code learning rate .03 and its bounded-gradient flip selector. Check-train NLL is 4.950776 at start, 4.844079 for scales alone and 4.839042 with codes. This train advantage **does not transfer** to complete-model text.

Before training, `run.py freeze` selected sixteen new nonoverlapping 256-token WikiText-2 test windows, excluding the pilot, fresh and latest-extrapolation fixture intervals. Eight were used for candidate selection; the last eight were withheld until the three complete images were frozen. Every window has 255 predictions. Full images are decoded from their packed trits/scales into BF16 for quality evaluation; this is not packed inference timing.

At equal raw bytes and 13 **fewer** paid bytes than the new scale-only image, coupled loses by **.002392 selection** and **.001612 ± .001404 held nats** (3/8 held windows favor coupled). Scales alone improve over source by .001281 selection and .003240 ± .002521 held nats (5/8 favorable), costing 64 paid bytes. These are small paired differences, not evidence of universal convergence or a Bonsai-quality image. The negative is specific to layer 14, eight steps, this sparse first-order STE selector and these fresh windows. It changes the next experiment: do not extend first-order trit flips from training gain alone; nominate a **composed multi-step** code/scale change and require a matched fresh scale-only control before another held complete-model panel. Qwen3.6 transfer still needs broad actual routed producers and a paid complete model image.
